# Security Policy

## Reporting a vulnerability

Please report vulnerabilities through GitHub's private vulnerability reporting: open the **Security** tab of this repository and click **Report a vulnerability**. Reports go straight to the maintainers and stay private until a fix is released. You can also email piotr.m@stagewhisper.io.

Please do not open public issues, pull requests or discussions for security problems.

A useful report includes:

- What the problem is and which component or URL it affects.
- Steps to reproduce it, or a proof of concept.
- The impact you believe it has.
- The app version or commit, and your operating system if it matters.
- How you would like to be credited, if at all.

## Supported versions

Security fixes target the latest version published to PyPI.

## What to expect

You will get a first response within 7 days. If the report is valid, we will work on a fix, release it, and credit you in the advisory unless you ask us not to.

## Safe harbor

We will not take legal action against research done in good faith that stays within these limits: do not access, change or keep other people's data, do not disrupt the service for other users, and give us reasonable time to fix the problem before you disclose it.

## Machine-readable contact

The same contact is published at https://stagewhisper.io/.well-known/security.txt.
